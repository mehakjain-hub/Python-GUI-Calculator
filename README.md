# Python Tkinter Multi-Function Calculator

This project is a robust, multi-function calculator built using Python's Tkinter library. It supports a wide range of operations including basic arithmetic, advanced mathematical functions, and utility features. The application includes comprehensive error handling to catch invalid inputs and prevent runtime errors. The user interface is designed with a clean, grid-based layout and a dark theme, making it both functional and visually appealing.

---

## Features

1. **Basic Arithmetic:** Addition (`+`), Subtraction (`-`), Multiplication (`x`), Division (`/`)  
2. **Advanced Functions:**  
   - **Percentage** (`%`)  
   - **Square** (`x²`)  
   - **Square Root** (`√`)  
   - **Reciprocal** (`1/x`)  
   - **Negation** (`±`)  
3. **Editing Functions:**  
   - Clear Entry (`CE`)  
   - Clear All (`C`)  
   - Backspace (`←`)  
4. **Decimal Support:** Handles floating-point numbers.  
5. **Error Handling:** Prevents division by zero, invalid inputs, and negative square roots. Displays `Error!` when necessary.  
6. **Dynamic State:** Entry field updates automatically based on user input and operations.  
7. **Aesthetics:** Dark theme (`#2e3440`) with high-contrast text and responsive button layout for a modern look.  

---
